## 📝 Формат `domain.txt`

Один домен — одна строка:

```text
youtube.com
googlevideo.com
ytimg.com
```

Панель автоматически:

- приводит домены к нижнему регистру;
- удаляет `http://` и `https://`;
- удаляет `www.`;
- удаляет путь после имени хоста;
- удаляет пробелы;
- удаляет пустые строки;
- удаляет дубликаты;
- сортирует список.

Например:

```text
https://www.YouTube.com/watch?v=123
```

превращается в:

```text
youtube.com
```

## 📱 Удобный ввод на телефоне

Все основные поля ввода настроены для Android и мобильных браузеров:

- отключена автокоррекция;
- отключена автоматическая капитализация;
- отключена проверка орфографии;
- отключено автозаполнение там, где оно не требуется;
- используется подходящая мобильная клавиатура;
- поля имеют удобную высоту для нажатия пальцем.

### Добавление домена

В поле домена пробелы удаляются сразу во время ввода.

Если клавиатура неожиданно вставляет:

```text
youtube. com
```

поле автоматически исправляет это на:

```text
youtube.com
```

### Массовое добавление

В большом поле можно вставлять список:

```text
youtube.com
googlevideo.com
ytimg.com
```

Переносы строк сохраняются, а случайные пробелы и табуляции удаляются.

## 🔐 GitHub Token

Token хранится **только локально в браузере**:

- `localStorage`;
- резервная копия — IndexedDB.

Token:

- не записывается в `domain.txt`;
- не отправляется в репозиторий;
- не вставляется в URL;
- не хранится в исходном коде сайта.

### Какие права нужны

Используйте **Fine-grained Personal Access Token** с правом:

```text
Contents → Read and write
```

Лучше ограничить Token только этим репозиторием:

```text
nektopandroid-source/forkop-list
```

GitHub указывает `Contents: write` как необходимое разрешение для создания или обновления содержимого файла. citeturn0search0

> ⚠️ Не передавайте свой Token другим людям и не публикуйте его в GitHub.

## ☁️ Как работает синхронизация

После добавления, редактирования или удаления домена:

```text
Панель
   ↓
изменяет список
   ↓
GitHub API
   ↓
domain.txt
   ↓
получается новый SHA
   ↓
повторное чтение GitHub
   ↓
панель показывает актуальный список
```

Записи выполняются последовательно, чтобы снизить вероятность конфликтов при одновременном изменении `domain.txt`. citeturn0search0

## 🔄 Обновление списка

Кнопка **↻** получает `domain.txt` заново через GitHub API.

Панель использует:

- `cache: no-store`;
- cache-busting параметр;
- повторное чтение после каждой записи.

Поэтому интерфейс не должен показывать старую сохранённую копию списка из браузерного кэша.

## ▶️ Использование

### 1. Откройте панель

Откройте страницу GitHub Pages вашего репозитория.

### 2. Добавьте Token

Раскройте:

**GitHub Token**

Введите Fine-grained Token и нажмите:

**Сохранить Token**

### 3. Управляйте списком

Можно:

- добавить домен;
- добавить несколько доменов;
- найти домен;
- изменить домен;
- удалить домен;
- выбрать несколько доменов;
- обновить список.

Все изменения автоматически сохраняются в `domain.txt`.
