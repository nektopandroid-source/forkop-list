# Forkop — список доменов

Веб-панель для удобного управления `domain.txt`, который используется Forkop.

## Возможности

- загрузка актуального `domain.txt` через GitHub Contents API;
- поиск по доменам;
- добавление одного домена;
- массовое добавление;
- редактирование;
- удаление одного домена;
- массовое удаление;
- выбор всех отображаемых результатов;
- нормализация доменов;
- удаление дубликатов;
- сортировка по алфавиту;
- автоматическое сохранение изменений в GitHub;
- повторное чтение файла после сохранения для проверки синхронизации;
- локальное сохранение GitHub Token;
- удобный ввод с Android/Chrome;
- адаптация интерфейса под телефон.

## Репозиторий

- **Owner:** `nektopandroid-source`
- **Repository:** `forkop-list`
- **Branch:** `main`
- **Файл:** `domain.txt`

Панель использует GitHub Contents API. Для обновления существующего файла GitHub использует Base64-кодированное содержимое и текущий `sha` файла. citeturn0search0

## Формат `domain.txt`

Один домен на строку:

```text
youtube.com
googlevideo.com
ytimg.com
```

Панель автоматически:

- приводит домен к нижнему регистру;
- удаляет `http://` и `https://`;
- удаляет `www.`;
- удаляет путь после домена;
- удаляет пробелы;
- удаляет пустые строки;
- удаляет дубликаты;
- сортирует список.

## Ввод с телефона

Поле **«Добавить домен»** использует:

```html
inputmode="url"
```

Также отключены:

- автокоррекция;
- автоматическая капитализация;
- проверка орфографии;
- автозаполнение.

Дополнительно пробелы удаляются **непосредственно во время ввода**.

Например, если Android-клавиатура сама вставляет пробел после точки:

```text
youtube. com
```

поле автоматически исправит его на:

```text
youtube.com
```

## GitHub Token

Token хранится локально в браузере:

- `localStorage`;
- резервно — IndexedDB.

Token не записывается в `domain.txt`, URL или исходный код репозитория.

Для изменения `domain.txt` нужен Fine-grained Personal Access Token с разрешением:

```text
Contents → Read and write
```

Рекомендуется ограничить Token только репозиторием:

```text
nektopandroid-source/forkop-list
```

GitHub указывает, что для Create or update file contents Fine-grained token должен иметь разрешение `Contents: write`. citeturn0search0

## Синхронизация

После добавления, редактирования или удаления:

1. изменяется локальный список;
2. новый `domain.txt` отправляется в GitHub;
3. получается новый `sha`;
4. файл повторно читается из GitHub;
5. интерфейс обновляется по фактическому содержимому файла.

Это предотвращает рассинхронизацию между интерфейсом и `domain.txt`.

Операции записи выполняются последовательно, поскольку GitHub предупреждает о конфликтах при параллельных операциях над одним файлом. citeturn0search0

## Обновление

Панель использует GitHub API, а не сохранённую копию списка браузера.

Запросы выполняются с отключением кэширования и с cache-busting параметром. Кнопка `↻` поэтому запрашивает актуальное состояние `domain.txt`.

## GitHub Pages

Панель является обычным статическим `index.html` и может размещаться через GitHub Pages. GitHub Pages публикует HTML/CSS/JavaScript непосредственно из репозитория. citeturn0search1turn0search3

## Использование

1. Открой панель.
2. Раскрой **GitHub Token**.
3. Введи Fine-grained Token.
4. Нажми **Сохранить Token**.
5. После успешной проверки загрузится список.
6. Добавляй, редактируй или удаляй домены.

Изменения автоматически записываются в `domain.txt`.

## URL списка для Forkop

Сам Forkop может получать список напрямую:

```text
https://raw.githubusercontent.com/nektopandroid-source/forkop-list/main/domain.txt
```

Панель управления использует GitHub API отдельно от этого URL.
